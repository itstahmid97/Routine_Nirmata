  Next.js ও ব্রাউজার-ভিত্তিক সংরক্ষণ

বিদ্যালয়ের শিক্ষক, বিষয় ও সাপ্তাহিক ক্লাস রুটিন সাজানো, তৈরি, সম্পাদনা,
প্রিন্ট এবং JSON ফাইলে সংরক্ষণের জন্য এই অ্যাপ তৈরি করা হয়েছে।

চালু করা
--------
Windows-এ “Start Application.bat” ফাইলে ডাবল-ক্লিক করুন। Node.js 20.9 বা নতুন
সংস্করণ লাগবে। বিকল্পভাবে টার্মিনালে এই ফোল্ডারে এসে চালান:

  npm install
  npm run dev

তারপর http://localhost:3000 খুলুন।

ডেটা কোথায় থাকে
---------------
• রুটিন IndexedDB-তে, এই ব্রাউজারের এই ওয়েব ঠিকানার জন্য সংরক্ষিত হয়।
• ব্রাউজারের সাইট ডেটা পরিষ্কার না করা পর্যন্ত পরেরবার ফিরে এলে ডেটা থাকবে।
• প্রথমবার চালু হলে public/routine-initial-state.json থেকে বর্তমান রুটিন কপি হয়।
  এরপরের পরিবর্তন শুধু ওই ব্রাউজারের কপিতে সেভ হয়।
• অন্য ব্রাউজার, অন্য ডিভাইস বা ভিন্ন ওয়েব ঠিকানায় ডেটা নিজে থেকে যাবে না।
  “JSON নামান” দিয়ে ফাইল নামিয়ে, “JSON আনুন” দিয়ে অন্য জায়গায় ইমপোর্ট করুন।
• “শিক্ষক মোড” শুধু দেখার জন্য; “প্রশাসক মোড” রুটিন সম্পাদনা ও ডেটা ব্যবস্থাপনার
  জন্য। এগুলো ব্রাউজারের মোড, পাসওয়ার্ড অ্যাকাউন্ট বা নিরাপত্তা ব্যবস্থা নয়।

Vercel-এ প্রকাশ
---------------
প্রকল্পটি GitHub-এ দিয়ে Vercel-এ Import করুন। Framework preset Next.js হিসেবে
স্বয়ংক্রিয়ভাবে শনাক্ত হবে; আলাদা ডেটাবেস পণ্য বা কানেকশন সেটআপ লাগবে না।
প্রতিটি ব্যবহারকারীর ডেটা তার নিজের ব্রাউজারে থাকবে। সবাই মিলে একই ডেটা সম্পাদনা
করতে চাইলে পরবর্তীতে শেয়ারড ডেটাবেস বা সিঙ্ক ব্যবস্থা যোগ করতে হবে।

পুরোনো HTML, frontend/ ও server/ কোড, SQLite ফাইল, backups/ এবং bundled Node
runtime স্থানীয় আর্কাইভ হিসেবে রাখা আছে; নতুন Next.js অ্যাপ চালাতে এগুলোর দরকার
হয় না এবং .gitignore-এর কারণে GitHub-এ যাবে না। GitHub-এ বর্তমান Next.js অ্যাপ,
সেটিংসের নিরাপদ নমুনা এবং প্রথমবারের রুটিন public/routine-initial-state.json থাকবে।
